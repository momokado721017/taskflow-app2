# TaskFlow PWA

TaskFlow v74 をベースに、スマホとPCでインストール可能なPWAとしてまとめた個人用パッケージです。

## 重要
- `index.html` を直接開く（file://）だけでは、インストール機能とオフラインキャッシュは有効になりません。
- インストールするには、HTTPSで配信してください。個人利用なら GitHub Pages などの静的ホスティングが使えます。
- データは現状、ブラウザの localStorage に保存されます。端末間で自動同期はされません。ブラウザのデータを消すとタスク等が消える可能性があるため、ブラウザデータ削除には注意してください。

## ファイル
- `index.html`: TaskFlow本体
- `manifest.webmanifest`: アプリ名・アイコン・表示設定
- `sw.js`: オフライン用キャッシュ
- `icons/`: インストール用アイコン

## インストール
1. このフォルダの中身をHTTPS対応の静的ホスティングへ配置します。
2. 配置したURLをスマホまたはPCのChrome/Edgeで開きます。
3. ブラウザのメニューから「アプリをインストール」または「ホーム画面に追加」を選びます。
4. iPhone/iPadはSafariで開き、「共有」→「ホーム画面に追加」を選びます。

初回起動時に一度オンラインで読み込むと、Service Worker が対応ブラウザでキャッシュを作成します。
